Como funciona

  1. 1

    O estabelecimento gera o código

    No atendimento ou pagamento, o local emite um código único para aquele comprovante, no formato {{ PREFIXO_CODIGO }}-0000.

  2. 2

    O cliente leva o código no cupom

    O código só vale para o estabelecimento que o emitiu. Quem não consumiu ou utilizou o serviço não consegue avaliar.

  3. 3

    A avaliação sai com selo

    Ao publicar, o código é queimado e nunca mais pode ser reaproveitado. Um comprovante, uma avaliação.
